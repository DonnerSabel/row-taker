## Vorschlag zur Organisation

Die Dateien sind bewusst mit einer Nummer versehen. So ist sofort erkennbar,
- in welcher Reihenfolge die Themen gedacht sind,
- welche Datei zu welchem Schüler oder welcher Schülergruppe gehört,
- und welche Texte Einzelthemen bzw. Gruppenthemen behandeln.

## Alternativer Ablageort im Repo

Für das eigentliche Projekt würde ich einen Ordner wie diesen empfehlen:

`docs/Schuelerfeedback/2026-03-22/`

Darin können die Dateien genau in dieser Form liegen. Das hat mehrere Vorteile:

- Datum und Anlass sind sofort erkennbar.
- Die Texte bleiben von allgemeiner Projektdokumentation getrennt.
- Spätere Rückmeldungen können in einem neuen Datumsordner abgelegt werden.

## Hinweis zum Inhalt

Die Texte sind fachlich an den aktuellen Stand des ZIP-Repos angepasst. Teilweise beschreiben sie ausdrücklich, **welcher Fehler vorher vorhanden war** und **warum die jetzige Lösung besser ist**.
